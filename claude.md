# System Prompt

This file will be replaced by the output of your Coaching Style Interview.

Until then, your agent has no custom instructions and will behave like a default Claude / Cursor / Code agent.

To populate this file:
1. Open the Coaching Style Interview prompt (`prompts/coaching-style-interview.md`)
2. Paste it into a new chat in this folder/project
3. Answer the questions
4. Replace the contents of this file with the rendered system prompt

# LinkedIn Profile

This file will be replaced by your LinkedIn export, converted to markdown. It lives in `context/` because it's static career reference, not a living document.

To populate it:
1. Open your LinkedIn profile in a browser, click "More" → "Save to PDF"
2. Convert the PDF to markdown using either:
   - Free, no-tokens: [pdf2md.morethan.io](https://pdf2md.morethan.io/)
   - Or upload to Claude/ChatGPT and ask: "Convert this LinkedIn PDF into a clean markdown profile. Keep all the facts but format as readable markdown. Don't summarise."
3. Replace the contents of this file with the markdown output

This adds your career arc to the agent's context. The role profile covers what you do *now*; LinkedIn covers *where you've been*.

# Role Profile

This file will be replaced by the output of your Role Profile Interview.

To populate it:
1. Open the Role Profile Interview prompt (`prompts/role-profile-interview.md`)
2. Paste it into a new chat in this folder/project
3. Answer the questions in order (or attach existing docs and let the model skip what's already covered)
4. Replace the contents of this file with the rendered role profile

This lives in `context/` because it's static reference material that you'll write once and update occasionally, not a living document.

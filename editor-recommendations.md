# Editing markdown files

You'll be editing `.md` files often. If you're not already comfortable with one, here are some free, easy options.

## Recommended (in order of friendliness)

### 1. StackEdit (no install, browser-based)
[stackedit.io](https://stackedit.io/) - works in any browser, free forever, no account required. WYSIWYG-style editor with live preview. Open a file from your desktop, edit, save back. Best for occasional editing.

### 2. Ghostwriter (free desktop app, all platforms)
[ghostwriter.kde.org](https://ghostwriter.kde.org/) - one-click installer for Windows, Mac, and Linux. Free forever, made by KDE. Distraction-free writing with live preview. Cleaner than Obsidian, less nerdy.

### 3. Cursor (free, more technical)
[cursor.com](https://cursor.com/) - one-click installer for Windows and Mac. Free forever for basic use. AI-powered code editor that handles markdown well. Good if you'll also start using it as your AI coding agent.

### 4. Obsidian (free, powerful, more nerdy)
[obsidian.md](https://obsidian.md/) - one-click installer for Windows and Mac. Free forever for personal use. Powerful but plugin-heavy and intimidating on day one. Best if you want to grow into a personal knowledge management system.

## Container-specific notes

- **Claude/ChatGPT Projects, Gemini Gem:** you don't need a markdown editor. Everything happens in Claude.ai, ChatGPT, or Gemini in the browser.
- **Cowork:** Cowork has a built-in editor. External editor only useful if you want to edit when Cowork isn't open.
- **Coding Agent (Claude Code, Cursor, Codex):** you're already using a markdown-aware editor.

*Answer each section in a few bullets - capture the essence, not the detail. You'll come back and elaborate later.*

> **For the agent running this:** check today's date first, and frame every section from it. "This quarter" and "next quarter" mean the real ones. From mid-November onwards, this is the end-of-year push: the rest of this year is a few working weeks with the holidays in the middle, so focus on the one result that would make this year feel finished, then on the year ahead and its first quarter (Q1). Name the actual year and quarter in each heading you use (for example "The rest of 2026" and "Q1 2027"), and in the file you save.

> **Have OKRs, a plan for this quarter, or a draft plan for next year?** Paste them somewhere in this file (or attach them as a separate file in the same project) and skip the bits that are already covered. Don't reinvent the wheel.

> **Stuck on a goal?** Here are three example goals, to show the shape of a good one. They're examples, not suggestions to copy: your goal should come from your own work.
>
> - **Finish the year:** "Get the three biggest client renewals signed before the Christmas break, so January starts with the year's revenue already in."
> - **Save time:** "Cut my weekly report from half a day to under an hour before the holidays, so I start next year with that time back."
> - **Set up next year:** "Go into January with next year's first-quarter plan signed off and the first two projects already scoped."
